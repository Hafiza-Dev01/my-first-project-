# Smart Student Assistant 📚

## About the Project
Smart Student Assistant is a beginner project designed to help students organize their studies and improve their learning.

## Goals
- Create a simple study timetable.
- Help students organize homework.
- Encourage better study habits.
- Explore how technology can support Ethiopian students.

## Technologies
- HTML
- CSS
- JavaScript
